# Accessibility Statement

> **Status:** University-review draft  
> **Release date:** 2026-07-26  
> **Important:** Replace bracketed institutional placeholders and obtain formal university approval before public deployment.

## Target
The project targets WCAG 2.2 Level AA for public, student and administrator workflows. Current source includes semantic landmarks, a skip link, visible focus, keyboard-operable dialogs, focus trap/restore, native selects, live status regions, 44–48px touch targets, 16px base text, dynamic page language and mobile safe-area handling. A browser-local accessibility panel lets users choose default/large/extra-large text, high contrast, always-reduced motion and low-effects rendering; preferences apply immediately and can be reset without changing account data.

## Known verification limits
Automated/static tests verify preference normalisation, persistence, root CSS hooks and control availability, but they do not replace assistive-technology and browser testing. Final certification requires keyboard-only review; NVDA/JAWS/VoiceOver or equivalent checks; 200% text zoom; contrast testing; reflow; focus-not-obscured checks; English/Sinhala/Tamil pronunciation/rendering; and Chrome, Edge, Firefox, Safari, Android and iOS review.
